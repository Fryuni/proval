# Record every fork change as an ADR

This repository is a fork of Proval that we sync with upstream regularly. To keep our own changes visible during each sync, every change made in this fork gets an ADR in `docs/adr/` that says whether upstream tracks it (with a link) or whether it must be preserved. The policy lives in the Fork Policy section of `AGENTS.md`.

This change is not tracked upstream. This policy, the Fork Policy section of `AGENTS.md`, and this `docs/adr/` directory are specific to the fork. Preserve them when syncing with upstream.
